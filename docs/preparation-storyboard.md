# 티푸 조리 클로즈업 연출

손님이 앉은 방향에서 도마를 내려다보는 구도. 얼굴은 프레임 위로 빠지고 앞발 두 개와 음식이 중심이 됩니다. 각 장면은 3.2초, 카메라 진입에는 첫 장면에 0.8초를 더 둡니다. 디저트는 마지막 손질 한 장면으로 표현합니다. 긴 발효·냉각·굽기는 완성 직전의 짧은 순간을 보여주는 생략 연출입니다.

## 수고했어 코스

- 차완무시: 달걀과 다시를 부드럽게 섞어요 → 약한 김으로 천천히 쪄요 → 고명을 올려 마무리해요
- 아부리 연어 초밥: 연어를 한 점씩 썰어요 → 밥 위에 연어를 올려 쥐어요 → 표면에 살짝 불향을 더해요
- 호지차 푸딩: 호지차 푸딩 위를 정리해요

## 충전 코스

- 버섯 다시 수프: 버섯을 먹기 좋게 썰어요 → 다시와 함께 은근하게 끓여요 → 따뜻한 수프를 그릇에 담아요
- 장어 솥밥: 장어를 노릇하게 구워요 → 따뜻한 밥을 고르게 담아요 → 장어를 가지런히 올려요
- 흑임자 모찌: 모찌에 흑임자를 살짝 뿌려요

## 기운 내 코스

- 유자 무절임: 무를 얇게 썰어요 → 유자 양념에 가볍게 버무려요 → 겹겹이 담아 마무리해요
- 새우 텐푸라 롤: 새우튀김을 바삭하게 익혀요 → 밥과 새우를 돌돌 말아요 → 롤을 잘라 접시에 담아요
- 레몬 소르베: 레몬 소르베에 작은 잎을 올려요

## 작은 위로 코스

- 단호박 계란찜: 달걀에 단호박을 섞어요 → 부드럽게 익도록 쪄요 → 단호박 고명을 올려요
- 연어 오차즈케: 밥 위에 연어를 얹어요 → 따뜻한 다시를 둘러 부어요 → 김과 파를 조금 올려요
- 딸기 다이후쿠: 딸기 다이후쿠에 고운 가루를 묻혀요

## 포근함 코스

- 된장 가지구이: 가지를 도톰하게 썰어요 → 된장 소스를 발라 구워요 → 노릇한 면이 보이게 담아요
- 게살 달걀 덮밥: 달걀과 게살을 섞어요 → 달걀을 촉촉하게 익혀요 → 밥 위에 포근하게 얹어요
- 밤 푸딩: 푸딩 위에 작은 밤을 올려요

## 괜찮아 코스

- 오이 초절임: 오이를 얇게 썰어요 → 새콤한 양념에 버무려요 → 참깨를 더해 담아요
- 도미 소금 초밥: 도미를 한 점씩 썰어요 → 밥 위에 도미를 쥐어 올려요 → 소금을 살짝 더해요
- 배 젤리: 배 젤리 위에 잎을 올려요

## 천천히 코스

- 두부 앙카케: 버섯 소스를 따뜻하게 끓여요 → 두부 위에 소스를 끼얹어요
- 버섯 솥밥: 버섯을 얇게 썰어요 → 밥 위에 버섯을 펼쳐요 → 따뜻한 솥밥을 마무리해요
- 바닐라 모찌: 바닐라 모찌를 둥글게 정돈해요

## 마음 정리 코스

- 토마토 다시 절임: 토마토를 손질해요 → 맑은 다시를 둘러요
- 흰살생선 초밥 3종: 흰살생선 세 점에 고명을 올려요
- 유자 셔벗: 유자 셔벗에 유자 껍질을 올려요

## 화풀이 코스

- 냉두부 폰즈: 차가운 두부에 폰즈를 둘러요 → 연어알을 조심히 얹어요
- 매콤 아부리 참치롤: 참치와 밥을 돌돌 말아요 → 참치 표면을 살짝 구워요 → 매콤한 소스를 얹어요
- 시트러스 소르베: 소르베에 감귤 껍질을 올려요

## 달래기 코스

- 새우 계란찜: 달걀과 다시를 섞어요 → 새우와 함께 부드럽게 쪄요 → 파를 조금 올려요
- 간장 버터 관자 솥밥: 관자를 버터에 구워요 → 간장 향이 밴 밥을 담아요 → 관자를 가지런히 올려요
- 캐러멜 푸딩: 푸딩 위에 캐러멜을 흘려요

## 다시 시작 코스

- 시금치 참깨무침: 시금치와 참깨를 무쳐요 → 작은 그릇에 소복이 담아요
- 연어·계란 초밥: 밥 위에 연어와 계란을 올려요 → 두 가지 초밥을 나란히 놓아요
- 고구마 양갱: 고구마 양갱 위를 장식해요

## 심심 탈출 코스

- 바삭한 연근칩: 연근을 얇게 썰어요 → 가볍고 바삭하게 튀겨요 → 겹겹이 쌓아 담아요
- 크런치 새우롤: 새우와 밥을 말아요 → 바삭한 튀김 부스러기를 얹어요
- 딸기 파르페: 파르페 꼭대기에 딸기를 올려요

## 몰입 코스

- 다시 계란말이: 달걀에 다시를 섞어요 → 얇게 익힌 달걀을 말아요 → 두툼하게 잘라 담아요
- 참치 아카미 초밥: 참치 아카미를 썰어요 → 밥 위에 참치를 올려 쥐어요 → 두 점의 간격을 맞춰요
- 말차 젤리: 말차 젤리 위에 참깨를 올려요

## 고요한 코스

- 연두부 참깨소스: 연두부에 참깨 소스를 둘러요 → 파와 참깨를 얹어요
- 광어 초밥: 광어를 얇게 썰어요 → 작은 밥 위에 포개요 → 한 점을 가운데 놓아요
- 두유 푸딩: 두유 푸딩에 잎을 올려요

## 느긋한 코스

- 제철 채소 오히타시: 채소에 다시를 가볍게 버무려요 → 물기를 정리해 그릇에 담아요
- 새우튀김 메밀소바: 메밀면을 익혀요 → 면 위에 새우튀김을 얹어요
- 팥 모나카: 팥 위에 모나카 껍질을 살짝 덮어요

## 두근두근 코스

- 연어 타르타르: 연어를 작은 조각으로 썰어요 → 채소와 가볍게 섞어요 → 연어알로 마무리해요
- 붉은새우 초밥: 밥 위에 붉은새우를 펼쳐요 → 연어알과 파를 올려요
- 복숭아 젤리: 복숭아 젤리에 작은 잎을 얹어요

## 행복 가득 코스

- 단새우 카르파초: 단새우를 꽃처럼 펼쳐요 → 가운데에 연어알을 올려요
- 3종 모둠 초밥: 세 가지 생선을 밥에 얹어요 → 색을 번갈아 나란히 놓아요
- 딸기 크림 모찌: 딸기 크림 모찌를 접시에 놓아요

## 셀프 축하 코스

- 관자 차완무시: 달걀과 다시를 섞어요 → 관자를 얹어 부드럽게 쪄요 → 고명을 조금 올려요
- 오도로 초밥: 참치 뱃살을 도톰하게 썰어요 → 밥 위에 살며시 쥐어요 → 두 점을 나란히 담아요
- 밤 몽블랑: 몽블랑 꼭대기에 밤을 올려요

## 모험 코스

- 와사비 완두콩 무침: 완두콩에 와사비를 섞어요 → 참깨를 살짝 뿌려요
- 와규 아부리 초밥: 밥 위에 와규를 얹어요 → 표면에 노릇한 불향을 입혀요 → 작은 귤 조각을 올려요
- 망고 다이후쿠: 망고 다이후쿠를 접시에 정돈해요

## 스페셜 코스

- 성게알 차완무시: 달걀과 다시를 섞어요 → 부드러운 차완무시를 쪄요 → 성게알을 조심히 얹어요
- 제철 프리미엄 초밥 3종: 생선과 새우를 밥에 올려요 → 세 점의 간격을 맞춰요 → 작은 꽃과 고명을 더해요
- 계절 과일 모찌: 과일 모찌의 단면을 앞으로 놓아요

## 포근한 베이커리 코스

- 졸린 강아지 우유빵: 우유 반죽을 강아지 모양으로 빚어요 → 따뜻하게 노릇노릇 구워요 → 작은 얼굴을 완성해요
- 노릇한 치즈 그라탱: 그라탱 재료 위에 치즈를 덮어요 → 치즈 표면을 노릇하게 구워요 → 샐러드를 곁들여요
- 티푸 크림 팬케이크: 팬케이크 위에 작은 티푸를 올려요
