# 티푸 제작 순서

## 확정된 공간

- 기존 손님 쪽 카운터 높이와 낮은 스툴은 유지.
- 중앙 작업 공간: 상판 안쪽 기준 가로 6.5, 깊이 약 4.075 장면 단위.
- 뒤 왼쪽에 실제로 파인 싱크볼과 수전, 옆 수건, 하부 수납장 배치.
- 가운데 앞쪽 도마에서 조리하고, 뒤 왼쪽 싱크대로 이동하는 동선을 사용.
- 위 수치는 실제 미터가 아닌 현재 장면의 상대적인 단위.

## 다음 작업: 티푸의 외형과 크기

참고 이미지: 사용자가 제공한 `Cozy Omakase with a Puppy Chef.png`.

- 살구빛 털, 늘어진 귀, 크림색 주둥이, 둥근 검은 코와 눈.
- 흰 셰프 모자와 조리복, 짧고 둥근 앞발, 작은 꼬리.
- 살짝 내려간 눈꺼풀과 조용하고 신중한 동작.
- 정면·측면·후면 기준 시안을 먼저 일치시킨다. 보이지 않는 뒤쪽은 새로 디자인해야 한다.
- 참고 이미지에서 정확히 복원된 모델이라고 표현하지 않는다.

## 모델과 애니메이션

1. 최종 털 표현 전에 단순한 입체 모델로 머리·몸·귀의 비율 확인.
2. 중심 위치 약 [0, 0, 0], 손이 닿는 도마 높이 약 2.1을 기준으로 키와 팔 길이 조정. 바닥부터 실제 키는 시안에 맞춰 정한다.
3. 몸통, 고개, 양팔, 귀, 꼬리를 움직일 수 있는 구조 제작.
4. 조리복과 털 재질을 다듬고 웹용 GLB 자산으로 정리.
5. 대기 → 주문지 읽기 → 끄덕임 → 조리 → 서빙 → 싱크대에서 정리 동작 제작.
6. 손과 도구, 접시가 맞닿는 지점과 카운터 충돌을 확인.
7. 웹의 주문 진행 상태에 애니메이션 연결. 메뉴 종류에 맞춰 칼질/냄비 동작을 구분.

우선 한 동작(고개 끄덕임 또는 접시 내밀기)을 완성하고 나머지 동작으로 확장한다.
현재는 공간 단계까지 구현했으며 티푸의 실제 모델·관절·애니메이션은 아직 없다.
