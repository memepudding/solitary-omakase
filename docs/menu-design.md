## 선택

- 주문지에서 자동 선택 또는 20개 코스 직접 선택.
- 정확한 음식명 우선. 관자 차완무시처럼 긴 이름이 일반 차완무시보다 높은 점수.
- 재료 이름을 비교할 때 ‘다시’, ‘제철’ 같은 일반 표현은 제외.
- 감정은 일치한 표현의 길이 합을 비교. 동률이나 미분류 문장은 문장 해시로 선택하고, 같은 방문 내 직전 코스는 동률 후보에서 제외.
- ‘피곤하지 않아’, ‘초밥 말고 장어’ 같은 짧은 부정 표현 제외. 외부 AI를 사용하지 않으며 복잡한 문맥은 놓칠 수 있음.
- ‘졸리다/자고 싶다’ → 충전, ‘집에 가고 싶다’ → 포근함, ‘쉬고 싶다’ → 천천히.
- `/menu-guide`에서 같은 분류 함수의 결과, 인식 표현, 모든 60개 음식 미리보기와 회전 가능한 3D 뷰어 제공.

## 자산과 영수증

- `lib/food-catalog.json`: 이름, 설명, 문구, 음식 ID, 코스의 단일 기준.
- `scripts/expand-foods.cjs`: 카탈로그 생성. `scripts/build-foods.mjs`: 48개 GLB 생성. `scripts/render-food-posters.mjs`: 그 GLB에서 실제 미리보기 PNG 렌더.
- 선택한 접시만 요청하며, 이름에 따라 독립 GLB를 로드. 새로운 모델도 평면 이미지가 아닌 회전 가능한 메시.
- 영수증 PNG에 종이 절취 가장자리와 투명 여백 포함. 세 음식 그림, 원래 주문, 설명, 표시 가격 $1.50, 저장 페이지 QR.
- QR은 메뉴 ID와 쪽지, 날짜를 주소 fragment로 담으며 서버 저장 없음. 공개 배포 전 localhost QR은 다른 기기에서 열 수 없음.
- 20개 코스 모두 QR 왕복 검증. 예전 수프/밥/셔벗 형식 호환 유지.
