# 원본 티푸 팔 리깅 — 첫 동작

사용자가 제공한 `public/models/teepu-chef.glb`를 원본으로 보존합니다. 새 몸통이나 앞발로 교체하지 않고 같은 메시, UV, 재질에 뼈대와 스킨 가중치를 추가했습니다.

## 파일

- 웹용 모델: `public/characters/teepu-rigged.glb`
- 편집 가능한 원본: `assets/characters/teepu-rigged.blend`
- 재생성: `scripts/rig-teepu.py` (Blender 3.6.4)
- 웹 미리보기: `/teepu-model` — 팔 내린 자세 / 앞발로 젓기 / 원본 자세
- 검증: `node tests/teepu-rig.mjs`

## 뼈대와 동작

Root, Spine, Head와 좌우 UpperArm / Forearm / Paw, 총 9개 뼈입니다. 얼굴·귀에는 팔 가중치를 부여하지 않습니다. 원본 16,169개 정점의 좌표는 리깅 중 바꾸지 않으며, GLB 내보내기 과정에서 UV/노멀 경계 정점 4개가 분리됩니다.

- `ArmsRelaxed`: 어깨를 내려 편안히 팔을 둔 자세. 팔꿈치 추가 굽힘은 5도.
- `StirRight`: 오른쪽 앞발을 몸 앞으로 가져와 3초 주기로 작게 젓기. 팔꿈치 추가 굽힘은 6도.

웹에서는 SkeletonUtils로 각 인스턴스의 뼈대를 복제하고, 두 동작을 0.35초 동안 섞어서 전환합니다. 숟가락은 실제 Paw.R 관절의 그립 위치를 따라갑니다. 움직임 감소 설정에서는 고정 자세를 사용합니다.

## 식당 반영 범위

기존 임시 조리용 몸통·소매·앞발은 제거했습니다. 원본 티푸를 계속 표시하며, 섞기·끓이기·밥 손질 장면에 젓기 동작을 연결했습니다. 손님 앞의 기존 큰 나무 도마를 조리 위치로 사용합니다. COOK_STATION에서 도마·음식·티푸의 조리 위치를 함께 관리하며, 티푸는 안쪽 발판 높이에서 도마에 맞춰 젓습니다.

이번 단계는 팔 내림과 젓기 두 동작에 한정됩니다. 칼질, 접시 집기, 장식 놓기는 아직 별도의 관절 동작이 아닙니다. 그 장면에서는 팔을 내린 자세로 음식 연출만 재생합니다. 발·귀·손가락의 독립 관절 및 IK는 포함하지 않습니다.

## 검증

Blender 정면·측면 렌더로 소매와 어깨를 확인했습니다. 내보낸 GLB를 Three.js에서 다시 읽어 9개 관절, 두 애니메이션, 내려간 앞발 높이, 젓는 앞발의 이동 및 얼굴·귀 8,674개 정점의 고정을 검사합니다. 빌드 후 미리보기와 실제 주문 흐름에서도 확인합니다.
